## 🍽️ Smart Restaurant Management & Pre-Order System

A full-stack restaurant management and pre-order platform designed to help restaurants manage their **digital menu, customer orders, table bookings, offers, coupons, loyalty rewards, and customer interactions** through a modern web application.

### ✨ Features

- 🍴 **Digital Menu** — Browse food items with details, categories, and pricing
- 🔎 **Menu Search** — Search for food items quickly
- 🛒 **Add to Cart** — Add food items to the shopping cart before placing an order
- 📝 **Pickup Order Booking** — Customers can place orders for pickup
- 📦 **Order Tracking** — Customers can track the status of their orders
- 👤 **User Registration & Login** — Customer account creation and authentication
- 🔐 **JWT Authentication** — Secure authentication using Spring Security and JWT
- 🔒 **BCrypt Password Encryption** — Secure password storage
- 👨‍💼 **Admin Panel** — Dedicated interface for restaurant administration
- 📋 **Order Management** — Admin can manage customer orders
- 👥 **Customer Management** — Admin can manage customer information
- 🍽️ **Menu Management** — Admin can manage food items and menu information
- 🗂️ **Category Management** — Admin can manage food categories
- 📱 **Responsive UI** — Designed for desktop and mobile devices
- ☁️ **Cloud Deployment** — Frontend and backend deployed to the cloud

# 🤖 AI Resume Analyzer Chatbot

An AI-powered **Telegram chatbot** that analyzes **one or multiple resumes against a Job Description** and generates an individual AI-powered analysis for each resume.

The chatbot helps candidates understand how closely their resume matches a specific job and identifies skills they may need to improve.

### ✨ Features

- 📄 **Multiple Resume Support** — Upload one or multiple resumes
- 📋 **Job Description Analysis** — Analyze resumes against a specific JD
- 📊 **ATS Score** — Generate an ATS-style compatibility score
- ✅ **Matching Skills** — Identify skills matching the Job Description
- ❌ **Missing Skills** — Identify required skills missing from the resume
- 📚 **Learning Suggestions** — Recommend skills to learn
- 🔗 **Course Links** — Provide learning resources for suggested skills
- 🤖 **Gemini AI** — AI-powered resume and JD analysis
- 📱 **Telegram Interface** — Complete analysis through Telegram
- 🐳 **Docker** — Containerized application
- ☁️ **Render Deployment** — Cloud deployment

### 🔄 Chatbot Workflow

```text
/start
   │
   ▼
📄 Upload Resume(s)
   │
   ├── Resume 1
   ├── Resume 2
   ├── Resume 3
   └── ...
   │
   ▼
/done
   │
   ▼
📋 Send Job Description
   │
   ▼
🤖 Gemini AI Analysis
   │
   ├── Resume 1 → Analysis 1
   ├── Resume 2 → Analysis 2
   ├── Resume 3 → Analysis 3
   └── ...
   │
   ▼
📊 Individual Results
```

### 📊 Analysis Provided for Each Resume

Every resume receives its own analysis containing:

```text
📊 ATS Score

✅ Matching Skills

❌ Missing Skills

📚 Learning Suggestions

🔗 Course Links
```

### 📄 Multiple Resume Analysis

The chatbot supports both single and multiple resume analysis.

```text
One Resume
     │
     ▼
One Individual Response


Multiple Resumes
     │
     ├── Resume 1 → Response 1
     ├── Resume 2 → Response 2
     ├── Resume 3 → Response 3
     └── Resume N → Response N
```
